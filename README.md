# FieldReport Kit, démonstration

Film de présentation d'une minute de FieldReport Kit, un logiciel de bureau pour les études de terrain : questionnaires, entretiens et rapport dans un seul outil, en français, qui fonctionne sans Internet et garde les données sur l'ordinateur.

Démonstration : https://djamal2905.github.io/fieldreport-kit-demo/

Les captures viennent du logiciel ; les données affichées sont fictives.
